Colab + Frontend Setup Guide

This frontend allows your team to query Python/C++/JS source code converted into PDF format. Here is how your teammate connects their backend:

  1. In Google Colab, run a Python FastAPI or Flask server that accepts POST requests with JSON containing pdf_base64 and query.
  2. Expose the Colab port using pyngrok or localtunnel (e.g. https://xxxx.ngrok-free.app/explain).
  3. Click the Status Badge in top navbar and paste that URL into the endpoint field.
  4. Upload your PDF, ask any question, and hit Analyze Code!
